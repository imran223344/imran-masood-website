# Imran Masood Professional Website

This is a static website ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a GitHub repository (for example: `imran-masood-website`).
2. Upload **all files and folders** from this package, keeping the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Under Source, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the public website address.

Important: because the site contains personal documents, consider keeping sensitive information such as CNIC private rather than publishing it publicly.
